# Pushover Desktop Client

## Delivery

**Autonomous delivery:** When the user starts work in this repository (an issue, spec, tickets or a description), agents may push the work branch and merge it into the default branch without a further request, provided all checks pass: the full test suite, linters, the review stage, and QA when it was run. A pull request is not required for a verified change. Scope changes still require the user's approval.
